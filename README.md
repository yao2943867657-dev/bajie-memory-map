# 把人生做成一张冒险地图

这是八戒取经经历的创意改编示例。四站故事是教学文案，风景插图为本项目原创 SVG，不是真实旅行记录或地理地图。不需要 API、安装依赖或数据库。

## 从零跟做

1. 准备四个阶段。每个阶段写地点/阶段名、标题、80字左右的故事和一句感想。不一定要真实地理位置，例如出生、第一次上学、毕业、第一份工作。
2. 选四张自己可以公开使用的照片，命名 `01.jpg` 至 `04.jpg`，放进 `images`。不要只把电脑上的图片路径给 AI；要把图片文件放进项目。
3. 在 Codex 中选一个新的项目文件夹，把本期起步提示词与素材交给它，生成 `index.html`、`style.css`、`data.js`、`app.js` 和 `images`。让它启动预览，并告诉你预览地址。Codex安装与账号是前置；本期不包含软件安装教学。
4. 已有本示例时，双击 `index.html` 可预览。让 AI 改 `data.js` 的四段内容和图片路径，改 `index.html` 的网站标题、介绍、封面与页脚。无需自己编辑代码。
5. 点击四个站点、上一站/下一站；缩窄浏览器检查手机排版。四张图片都应显示，切换时地点、图片、正文应一起变化，首尾按钮应禁用。
6. 在 github.com 登录。右上角 `+` → `New repository`，输入自己的仓库名，例如 `my-memory-map`，选择 Public，创建仓库。公开站点里的内容将能被别人访问，使用你愿意公开的材料。
7. 新仓库点 `uploading an existing file`（已有文件时用 `Add file` → `Upload files`）。把网站文件及 images 文件夹内容上传；`index.html` 必须在仓库顶层，不能外套 site 文件夹。提交 `Commit changes`。
8. `Settings` → `Pages` → `Build and deployment` → `Source` 选择 `Deploy from a branch`，分支选择实际主分支（通常 main），目录选 `/(root)`，点 `Save`。
9. 等发布完成，在 Pages 页面打开网站链接。格式通常是 `https://用户名.github.io/仓库名/`。GitHub仓库链接是代码页面，Pages链接才是成品网站。
10. 用手机打开实际发布链接，点击四站，再分享。要更新时，把 AI 修改好的文件上传覆盖并提交；等待发布完成后刷新复查。

## 排错

- 404：检查发布是否完成、分支是否正确、index.html是否在顶层，是否打开 Pages 给的网址。
- 图片不见：文件名大小写一致，使用 `images/01.jpg` 这样的相对路径；不要用 `C:/...` 或 `/images/...`。
- 手机文字挤：给 AI 截图和屏幕宽度，让它只修手机布局，再测试桌面。
- 看起来没更新：等 Actions/Pages 发布成功，强制刷新；再核对上传的是否为最新文件。
- AI只有建议没文件：明确要求在当前文件夹生成文件并启动可访问预览。

## 起步提示词

我是零基础。请在当前文件夹做一个中文单页“人生冒险地图”。首页有标题、简介和封面；下面有四个按经历先后排列的站点，点击后同步显示对应图片、标题、故事和感想；有上一站、下一站，首尾禁用越界按钮。用手绘山川和照片手帐的视觉，松绿色配浅色背景，重点是可读和好看。手机改为上下排布。只用HTML/CSS/JavaScript，所有图片在images里，使用相对路径，不使用框架、外部API、账号或数据库。素材见我提供的四段内容和图片；缺少资料先问我，不要编造我的经历。请生成实际文件，启动预览，告诉我如何打开、修改和上传到GitHub Pages。最后检查四站切换、手机布局和图片路径。
